## Contexto do Projeto
Este projeto consiste na modelagem e implementação de um banco de dados relacional para o gerenciamento de um Empório de Bebidas / Adega. O escopo abrange o cadastro de clientes e seus respectivos endereços, a organização de um catálogo de produtos divididos por categorias (com especificações técnicas exclusivas para bebidas, como teor alcoólico e volume), e o processamento completo de vendas. O sistema suporta vendas nas modalidades de entrega (com cálculo de frete) e retirada no balcão.

## Ambiente de Execução (Docker)
O banco de dados foi configurado para ser executado de forma totalmente automatizada via contêiner, garantindo que o SGBD suba com a estrutura (DDL) e os dados (DML) já inicializados.
